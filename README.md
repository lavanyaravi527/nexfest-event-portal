NexFest 2025 — College Fest Event Portal
A feature-rich, single-page web application built with pure HTML, CSS, and JavaScript for managing college festival registrations, payments, and administration.

🌐 Live Demo


📌 Features
🎓 Student Side

Login System — Students enter their name, registration number, and password to access the portal
Event Registration — Register for 17+ events across 3 categories: Technical, Cultural, and Sports
Multi-step Payment Flow — Simulated payment gateway supporting UPI, Card, Net Banking, and Pay at Desk
My Dashboard — View, edit, search, and delete your registered events with live status
Payment History — Track all transactions with TXN IDs and payment status
Event Details Modal — View prize pool, venue, date, time, rules, and description for every event
Schedule Page — Full event timeline with live/upcoming/done status indicators
Real-time Notifications — Get notified on registration, payment confirmation, and event reminders

🛡️ Admin Side

Secure Admin Login — Separate login with credentials for organizers
Registrations Tab — View and manage all student registrations in a sortable table with CSV export
Event Manager — Add, edit, and delete custom events with full details (venue, prize, fee, rules)
Payments Tab — Monitor payment stats including total revenue, paid, pending counts
Analytics Tab — Visual bar charts showing registrations by category and top departments
